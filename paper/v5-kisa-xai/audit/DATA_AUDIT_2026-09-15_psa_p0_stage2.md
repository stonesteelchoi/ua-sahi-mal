## 2. §5 metadata-only shortcut — 게이트 통과 실패

바이트에서 유도 가능한 20개 변수만으로 로지스틱 회귀, **그룹 분리 5-fold**:

> **AUROC = 0.9499 ~ 0.9526** → 프로토콜 §5의 0.90 게이트를 넘김.

`submitted`·`total`·`positives`는 파일에 없는 수집 메타데이터이므로 모델 입력에서 제외했다.
(`positives`의 AUROC 1.0000은 eligibility 규칙이 만든 동어반복이며 발견이 아니다.)

### 2.1 Ablation — shortcut이 **중복적**이다

| 변수군 | 단독 | 제거 시 | 제거 효과 |
|---|---|---|---|
| toolchain | 0.8825 | 0.9078 | +0.0422 |
| entropy | 0.8219 | 0.9385 | +0.0114 |
| structure | 0.7457 | 0.9455 | +0.0045 |
| size | 0.7059 | 0.9360 | +0.0140 |
| signing | 0.6239 | 0.9310 | +0.0190 |

각 군이 단독으로 강한데 어느 하나를 빼도 거의 떨어지지 않는다. 다섯 채널이 같은 잠재변수를
중복 인코딩한다는 뜻이며, **변수 선택으로는 해결할 수 없다.**

### 2.2 잠재변수의 정체 — 15년 툴체인 격차

`linker_major` 최빈값:

| | 상위 5 |
|---|---|
| 정상 | 8(17,566), 11(16,234), 9(13,783), 12(11,832), 10(7,892) → **VS2005~2013** |
| 악성 | **6(33,131)**, **2(20,516)**, 9(11,643), 10(9,699), 8(8,981) → **VC6(1998)·Delphi 계열** |

`timestamp` 중앙값도 정상 1,417,096,303(2014-11) vs 악성 1,333,960,779(2012-04)로 벌어진다.
정상은 2018년 Windows 계열 수집, 악성은 Malicia(2013~2015) 계열이므로 **제작 연대를 맞히면
라벨이 맞는다.** 이는 수집 경로가 만든 순수 아티팩트다.

## 3. 매칭 — 아티팩트와 실제 특성을 가르기

첫 시도는 크기·엔트로피·linker로 매칭해 AUROC를 0.9499 → **0.8647**로 낮췄다. 그러나 이 설계는
**개념적으로 틀렸다**: 패킹(엔트로피)과 GUI 서브시스템은 수집 아티팩트가 아니라 **실제 악성코드
특성**이므로, 매칭으로 지우면 연구 대상 자체를 지우게 된다.

그래서 **연대 변수(`linker_major`, `linker_minor`, `timestamp`)에만** 매칭하는 `--match-on era`를
추가해 다시 측정했다.

| | 전체 | era 매칭 |
|---|---|---|
| 표본 | 199,316 | **70,938** (35.6%, 정상 35,469 / 악성 35,469) |
| **결합 AUROC** | 0.9499 | **0.9028** |

### 3.1 era 매칭이 실제로 한 일 (검증)

연대 변수는 정확히 무력화됐고, 실제 특성 변수는 유지되거나 오히려 강해졌다.

| 변수 | 전체 | era 매칭 | 판정 |
|---|---|---|---|
| `linker_major` | 0.2222 | **0.5000** | 아티팩트 — 제거됨 |
| `timestamp` | 0.3530 | **0.5015** | 아티팩트 — 제거됨 |
| `linker_minor` | 0.5563 | 0.4987 | 아티팩트 — 제거됨 |
| `dll_characteristics` | 0.2833 | 0.5494 | **연대 대리변수였음**(DEP/ASLR 플래그) — 제거됨 |
| `signed` | 0.3621 | 0.4621 | 대부분 연대 대리변수 — 붕괴 |
| `max_section_entropy` | 0.8223 | **0.8576** | 실제 특성 — 강해짐 |
| `file_entropy` | 0.7592 | **0.7701** | 실제 특성 — 강해짐 |
| `size_of_image` | 0.6360 | 0.6693 | 유지 |
| `subsystem` | 0.2372 | 0.3013 (대칭 0.6987) | 실제 특성 — 유지 |
| `is_pe32plus` | 0.3283 | 0.3256 (대칭 0.6744) | 유지 |
| `nonstandard_section_names` | 0.7057 | 0.6182 | 일부 감소, 유지 |

`subsystem` 분포: 악성은 GUI(2) 108,493 대 콘솔(3) 5,073, 정상은 콘솔 49,174 대 GUI 34,579.
악성코드가 콘솔 창을 띄우지 않으려는 실제 습성이다.

### 3.2 해석

**연대 아티팩트를 완전히 제거해도 metadata-only AUROC는 0.9028로 거의 유지된다.**
남는 신호는 패킹 엔트로피(0.858)·파일 엔트로피(0.770)·서브시스템(0.699)·PE32+(0.674)·
섹션 명명(0.618)이며, 이들은 수집 방식이 아니라 악성코드의 실제 정적 특성으로 볼 근거가 있다.

첫 매칭(0.8647)이 더 낮았던 것은 실제 특성까지 지웠기 때문이므로, **0.9028이 정직한 수치다.**

### 3.3 era 매칭 부분집합의 한계 (반드시 명시할 것)

양쪽 클래스가 모두 존재하는 셀만 남기므로, **정상이 없는 구형 툴체인 악성(linker 6·Delphi 약 5.4만)이
대량 탈락**한다. 악성은 114,388 → 35,469(31%), 정상은 84,928 → 35,469(42%)만 남는다.
즉 이 부분집합은 "2005~2013년 툴체인으로 만들어진 악성 대 정상"이며, 일반 모집단이 아니다.

## 3.4 era 부분집합의 분할 (동결 후보)

`--restrict-to matched_sample_ids_era.txt --tag era` 결과.

| 항목 | 값 |
|---|---|
| 표본 | 70,938 — 정상 35,469 / 악성 35,469 (완전 균형) |
| train / val / test | **49,658 / 10,646 / 10,634** (70.0 / 15.0 / 15.0) |
| `split_sha256` | `5f5ccde8f1f178fce85c63c84809c0fe46c00b7812577fb80bdfe6bf9da0b6d8` |
| 결합 metadata AUROC | **0.9112** (drill-down 구현에서는 0.9028) |

두 스크립트가 독립 구현으로 0.903~0.911을 내놓았다. fold 배정 세부가 달라 생긴 차이이며,
보고 시에는 **0.90~0.91 구간**으로 적고 단일 소수점을 주장하지 않는다.
test 10,634개는 쌍체 부트스트랩 2,000회에 충분하다.

### 3.4.1 era 매칭이 제거하지 **못한** 것

수집 메타데이터(모델 입력 아님)는 이 부분집합에서 오히려 더 선명해졌다.

| 변수 | 전체 | era 매칭 |
|---|---|---|
| `submitted_ts` | 0.7778 | **0.8380** |
| `total` | 0.6949 | 0.7282 |

즉 era 매칭은 연대 교란의 **바이트에 드러나는 표현(툴체인·컴파일 날짜)** 만 제거했을 뿐,
정상과 악성이 서로 다른 채널로 수집됐다는 사실 자체는 그대로다. 논문에서 이 구분을 분명히 해야 한다.

### 3.4.2 표현 정책 교란이 **악화**됐다

| | nearest_repetition 비율 |
|---|---|
| 전체 데이터 | 정상 29.4% vs 악성 8.1% (3.6배) |
| **era 부분집합** | **정상 24.1% vs 악성 5.0% (4.8배)** |

`interval-binned-v1`의 두 정책이 클래스와 상관되는 정도가 주 분석 데이터에서 더 커졌다.
동결 전에 다음을 프로토콜에 반영한다.

1. `repr_policy`를 manifest 필드이자 **분할 층화 변수**로 추가(현재 층화는 label·PE kind만).
2. 정책별 subgroup으로 H1/H2를 각각 보고.
3. **민감도 분석**: `mean_pool` 경로만으로(50,176 B 이상 파일만) H1/H2를 재검정.
   이 경로만 쓰면 정상 26,919 / 악성 33,681로 여전히 충분하다.

## 4. 결론과 결정 사항

1. 프로토콜 §5 문언대로면 매칭 후에도 효과가 유지됐으므로(0.9028 ≥ 0.90) 주 결론을
   `dataset-specific static discrimination`으로 제한해야 한다.
2. 다만 이번 분석은 그 제한보다 정밀한 구분을 제공한다 — **연대 아티팩트는 제거 가능하고 제거했으며,
   남은 분리력은 정적 악성 특성에서 온다.** 따라서 §5 종료 규칙을
   「아티팩트 주도 → 제한」과 「특성 주도 → 축소된 문구로 진행」으로 나누는 **프로토콜 개정**을 제안한다.
   모델을 아직 한 번도 학습하지 않은 지금이 개정의 유일하게 정당한 시점이다. 새 protocol ID를 부여한다.
3. 주 분석 데이터는 **era 매칭 부분집합**(70,938, 균형)으로 하고, 전체 199,316은 robustness로 둔다.
   분할은 부분집합 안에서 그룹 분리로 다시 만든다.
4. metadata-only AUROC **0.9028을 필수 보고 기준선**으로 삼는다. CNN의 AUROC가 0.97이라면
   0.90 위의 증분만이 "의미"의 후보다.
5. 제목과 주장에서 "악성 판정 근거"라는 표현은 쓸 수 없다. 2018년 단일 수집이므로 "교차연도"도 불가.

### 4.1 검증 가능한 예측

`interval-binned-v1`에서 PE 헤더는 래스터 좌상단의 소수 픽셀에 대응한다. 위 분석이 맞다면
Grad-CAM은 헤더보다 **패킹된(고엔트로피) 실행 섹션**에 몰려야 한다. §11의 구조별 CAM mass
enrichment가 이를 직접 판정한다. 헤더에 몰린다면 모델이 남은 연대 대리변수를 쓰고 있다는 뜻이다.
