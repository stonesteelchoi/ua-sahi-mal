## 3. V5.0-DRAFT 설계와의 충돌

V5.0-DRAFT와 `HANDOFF_PROMPT_KO.md`는 archive를 로컬 Windows GPU 장비(`D:\secure-malware-data\kisa`)로 내려받아 처리하는 것을 전제한다. 현재 확인된 유일한 활성 채널(사이버보안빅데이터센터)은 **원본 반출 불가·방문 분석·폐쇄망**이다. 따라서 다음이 확인되기 전에는 P0 Go 판정을 내릴 수 없다.

1. 센터 `데이터셋 리스트`에 2017·2018(·2019) 챌린지 데이터셋이 포함되는지
2. 폐쇄망 GPU PC에 PyTorch 2.8 + CUDA, torchvision, pefile, grad-cam, scikit-learn, scipy와 저장소 코드를 사전 반입·설치할 수 있는지(오프라인 wheel 번들, ImageNet 사전학습 가중치 파일 포함)
3. 반출 가능 산출물의 범위: 집계 통계·해시·비가역 CAM 집계는 가능해 보이나, 224×224 interval-binned raster, pixel↔offset map, per-sample CAM, ResNet-18 checkpoint가 "원본 식별 불가"로 인정되는지
4. 1회 방문당 이용 시간과 예약 가능 일정(3-seed 학습 + deletion/keep-only + bootstrap을 방문 창 안에 끝낼 수 있는지)

원본 반출 불가가 확정되면 V5.0-DRAFT를 덮어쓰지 않고 **온사이트 폐쇄망 실행**을 전제로 한 새 protocol revision을 만들고, P1–P9 코드를 오프라인 wheel 번들과 합성 fixture로 사전 검증한 뒤 방문한다.
