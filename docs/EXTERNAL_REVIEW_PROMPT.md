# 외부 LLM 검토 요청 프롬프트

> 아래 `---` 아래 전체를 복사해서 다른 LLM에 붙여넣으세요. 저장소를 함께 공유하면 §2의 경로를 그대로 읽을 수 있습니다.

당신은 악성코드 분석과 설명가능 AI(XAI)를 함께 아는 연구자입니다. 제가 진행 중인 연구의 현황을 검토하고, 논문으로 성립시킬 수 있는지 판단해 주세요. **결론을 부드럽게 포장하지 말고, 안 되는 것은 안 된다고 말해 주세요.**

## 1. 연구 개요

**과제**: 악성코드를 이미지로 변환했을 때, 분류기의 판정 **근거가 되는 바이트 구간**을 찾아낼 수 있는가.
**투고 목표**: 한국정보기술학회(KIIT) — 5쪽 내외 국문 논문.
**현재 상태**: 세 개의 실험을 완료했고 **전부 부정 결과**입니다. 성능 향상은 어디서도 얻지 못했고 주장하지도 않습니다.

연구 질문이 두 번 바뀌었으며, 그 변천 자체가 측정에 근거합니다.

```
v1  "어느 바이트 구간이 악성인가?"
     ├─ 공개 벤치마크에 바이트 수준 경계 라벨이 없다 (전부 파일 단위)
     └─ BIG2015 검체는 대부분 파일 전체가 악성 → "위치"의 지시 대상이 없다
        ↓
v2  "어느 바이트 구간이 계열 판정의 근거인가?"
     ├─ 인과적 정의: 가리면 못 맞히고(필요성), 그것만 남겨도 맞힌다(충분성)
     ├─ 사람 주석 불필요 — 마스킹 후 재추론이라는 연산으로 검증
     └─ 순환 평가 방어: 탐색에 쓰지 않은 독립 모델 + 이미지를 안 보는 모델
        ↓
    측정 결과: 정의는 되지만, 이 데이터에 국소적 답이 존재하지 않는다
```

## 3. 지금까지의 결과

### 실험 1 — MC dropout은 보정을 악화시킨다

MaleVis 26 클래스, 3 seed, 결정론적 vs MC dropout(5 pass).

| 차이 (MC − 결정론적, 224) | 값 | 95% CI | 유의 |
|---|---|---|---|
| 정확도 | +0.0112 | [−0.0067, +0.0291] | 아니오 |
| Macro F1 | +0.0014 | [−0.0108, +0.0135] | 아니오 |
| **ECE** | **+0.0905** | **[+0.0709, +0.1102]** | **예** |
| p95 지연 비 | 16.4배 | — | — |

ECE 0.048 → 0.138 (2.9배 악화). 사전 게이트 미달 → 채택 불가.
부수: 해상도 224→300은 결정론적 macro F1을 **낮춘다** (−0.0174 [−0.0329, −0.0019]).

### 실험 2 — 경계 인식 업샘플링이 bilinear를 못 이긴다

BIG2015 실제 검체, PE 섹션 시작 경계 복원, 오차 단위는 바이트.

| 셀 내 경계 위치 | nearest | **bilinear** | JBU(바이트 가이드) | JBU(엔트로피 가이드) |
|---|---|---|---|---|
| 0행 (정렬) | 0 | **0** | 1,609 | 0 |
| 1–4행 평균 | 1,280 | **597** | 2,987 | 1,109 |

**원인**: 바이트 이미지의 영역 경계는 값이 아니라 **분포**가 바뀌는 지점.
섹션 경계 전후 Cohen's d — 바이트 값 **0.96** vs 행 엔트로피 **8.50** (8.8배).
bilateral 커널은 값 유사도로 가중하므로 반응할 대상이 거의 없다.

**추가 발견**: `.bytes`는 VA 공간 덤프라 정렬 단위가 `FileAlignment`(0x200)가 아니라 `SectionAlignment`(0x1000). 폭 512에서 P3 한 셀이 정확히 4,096 B이므로 섹션 경계가 셀 경계와 겹쳐 **복원할 셀 내부 정보가 애초에 없다.**

**주의**: UA(Upsample Anything) 자체는 측정하지 못했다. 공개 구현이 CUDA 전용이고 최적화 스텝이 5,100회(논문 본문은 50회)라 CPU 불가. 고정 JBU로 대리했으므로 이 결과는 그 계열의 **하한**이다.

### 실험 3 — 근거 구간은 국소화되지 않는다

BIG2015 계열 층화 1,636 검체(계열당 200 상한), 판정 부분집합 45 검체, 블록 4,096 B, 예산 1/16.

**분류기 3종** (서로 다른 구조·seed·표현, 교차 검증용):

| 모델 | 표현 | 정확도 | macro-F1 |
|---|---|---|---|
| A (탐색용) | 512×512 바이트 타일, 원해상도 | 0.797 | 0.732 |
| B (주 지표) | 256×256 전체 이미지 | 0.877 | 0.850 |
| C_text | 히스토그램 + 해시 bigram (이미지 안 봄) | 0.590 | 0.522 |

**사전등록 판정표**:

| # | 조건 | 관측 | 임계 | 판정 |
|---|---|---|---|---|
| D1 | 합성 통제 Byte-IoU | **0.000** | ≥ 0.50 | 실패 |
| D2 | ΔNLL_B − 무작위 대조 | +0.030 [−0.034, +0.107] | CI가 0 제외 | 실패 |
| D3 | ΔNLL_text − 무작위 대조 | **+0.041 [+0.011, +0.075]** | CI가 0 제외 | **통과** |
| D4 | 채움값 3종 Kendall τ | 0.338 (최소 −0.348) | ≥ 0.60 | 실패 |
| D5 | Evidence Recall @ 1/16 | 0.217 | ≥ 0.70 | 실패 |
| D6 | UA − bilinear | 미측정 | +3.0 %p | — |

**핵심 관측 1** — 전수 오클루전 45검체·평균 232.8블록·10,521 순전파에서 검체당 근거 질량 합계가 **1.30**. 즉 **블록당 평균 ΔNLL = 0.0056**. 4 KB를 가려도 정답 계열 우도가 사실상 안 움직인다.

**핵심 관측 2** — 감도 곡선. 계열 Y의 창만 남기고 나머지를 계열 X 바이트로 덮은 검체 12개:

| 보존 비율 | 분류기가 Y로 예측 | Δ_근거 | Δ_무작위 대조 | CI가 0 제외 |
|---|---|---|---|---|
| 5% | 1/12 | +0.006 | +0.012 | 아니오 |
| 10% | 1/12 | −0.010 | −0.055 | 아니오 |
| **20%** | 1/12 | **+0.177** | −0.318 | **예** |
| 30% | 1/12 | +0.414 | −0.042 | 아니오 |
| 50% | 3/12 | +1.434 | +1.420 | 아니오 |
| 70% | 3/12 | +2.496 | +2.381 | 아니오 |

읽히는 것 세 가지: (a) 작은 창(≤10%)에서는 신호가 없다, (b) 큰 창(≥50%)에서는 무작위 대조군이 같은 내용을 덮어 통제 구실을 못 한다, (c) **12개 중 1–3개만 분류기가 해당 계열로 예측했다** — 다른 계열 바이트로 덮으면 덮은 쪽 계열로 판정한다.

**핵심 관측 3** — D1이 0.000인 것은 버그가 아니다. 양성과 **매칭된 하드 네거티브가 정확히 같은 0.000**이다. 16 KB 이식은 2.35 MB의 0.7%이고, 이식 구간 마스킹 시 donor 계열 ΔNLL이 양성 **−3.635**, 네거티브 **−3.684** — 같은 값이고 부호가 **음수**다(가리면 donor 우도가 오히려 오른다). 순수한 마스킹 아티팩트다.

**핵심 관측 4** — 라우팅 자체는 작동한다:

| 라우터 | Evidence Recall | 검체당 순전파 |
|---|---|---|
| coarse-occlusion + JBU | 0.236 | 21.1 |
| coarse + bilinear | 0.217 | 21.1 |
| uniform | 0.154 | 16.0 |
| entropy | 0.125 | 16.0 |
| random | 0.065 | 16.0 |
| *(전수 탐색)* | *1.000* | *233.8* |

무작위의 3.3배, 엔트로피 휴리스틱의 1.7배. 신호는 실재하나 기준(0.70)에는 크게 미달.

**현재 해석**:

> 바이트 이미지 계열 분류기는 국소 구간이 아니라 **전역 바이트 통계**에 의존한다. 근거가 숨어 있어서 못 찾는 게 아니라 **분산되어 있어서 "지역화"라는 서술이 적용되지 않는다.** D3 통과가 이와 어긋나지 않는다 — n-gram 히스토그램은 정의상 전역 통계라 어디를 가리든 조금씩 흔들린다.

### Q1 (최우선) — 선행 연구 확인

- 악성코드 이미지에 오클루전/deletion-insertion 기반 설명을 적용하고 **인과적으로 검증**한 연구
- 바이트 수준 근거 귀속(evidence attribution)을 **교차 모델 또는 교차 표현**으로 검증한 연구
- MalConv 계열의 attribution을 구간 단위로 평가한 연구
- 악성코드 이미지 분류기가 **전역 통계에 의존한다**는 것을 보인 연구 (제 실험 3의 결론과 겹치는지)
- 바이트 이미지에서 경계 인식 업샘플링이 실패함을 보인 연구 (실험 2와 겹치는지)

검색어 예: `malware occlusion explanation byte`, `malware image saliency localization evaluation`, `deletion insertion metric malware`, `byte-level evidence attribution malware classifier`, `MalConv attribution region`, `malware image classifier global statistics`

**겹치는 연구가 있으면 기여 주장을 어디까지 줄여야 하는지도 함께 말해 주세요.**

### Q4 — "근거가 분산되어 있다"를 더 직접 입증할 실험

현재 이 주장은 세 개의 간접 증거(블록당 ΔNLL 0.0056, Evidence Recall 0.217, 감도 곡선)에 기대고 있습니다. 더 직접적으로 보일 수 있는 실험이 있습니까? 제가 생각한 것:
